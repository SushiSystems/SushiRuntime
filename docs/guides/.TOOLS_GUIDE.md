# CLI quick reference

Install once (Windows → pipx, Linux/macOS → pip):

```
python install_cli.py
```

This puts two equivalent commands on your PATH: `sr` (short) and `sushiruntime` (long).
Everything below works with either name.

## Docker

```
sr docker build
sr docker run            # add --admin for --privileged (profiling)
```

## Build

```
sr project build                     # release (default)
sr project build --type debug        # TSan
sr project build --type asan         # AddressSanitizer (isolated build-asan tree)
sr project build --distributed       # master-worker layer
sr project build --clean             # wipe the tree first
sr project build --no-cuda           # Linux: disable the CUDA backend
```

## Test

```
sr project test --suite functional
sr project test --suite benchmark
sr project test --suite all
sr project test --suite functional --filter 'Steal.*'   # ctest -R over test names
```

## Run

```
sr project run                       # default target from config
sr project run --sort                # interactive picker
sr project run sr_benchmark_tests -- --gtest_filter='AllocatorBench.*'
sr project run --distributed=master  # forward a role to the app
```

## Docs

```
sr project doxygen
```
